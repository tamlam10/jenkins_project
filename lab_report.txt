I added Coverage and Security Scan stages to the Python-CI-CD pipeline.
Coverage runs the tests with coverage.py and generates text, XML and HTML
reports. The build requires 100% coverage of app.py. Bandit scans app.py
and saves its results as JSON. Any finding stops the pipeline before deployment.

The Deploy stage runs deploy.sh, which copies app.py to a local deployment
folder under JENKINS_HOME. It runs the deployed copy and checks that the
output is "Hello, World from Tamer Lammam!". This folder is outside the
workspace, so it stays available after cleanWs() removes the workspace.
Jenkins archives the reports and publishes the test results before cleanup.

I made the greeting match the personalized test in the lab. I also added
pytest, coverage and bandit to requirements.txt, since the original file
only listed flake8. The pipeline calls the virtual environment executables
directly, which works with Jenkins' default shell without using source.
